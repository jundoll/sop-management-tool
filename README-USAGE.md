# SOP管理システム - 利用者向け操作ガイド

SOP作成者・レビュー者・作業者（実施者）・チェック者向けの操作説明です。

## 対象ロール

- SOP作成者（管理者）
- レビュー者
- 作業者（実施者）
- チェック者

## 動作環境

- Microsoft Edge 最新版
- HTTPS環境（必須）

## 1. SOP作成者（管理者）の操作

管理者画面でSOPの作成・編集を行います。

### 1.1 ステップ管理

- 作業指示内容を入力
- 各ステップの設定:
  - 画像添付を許可
  - 時刻記録を必須
  - OK/NG判定を必須
  - スキップを許可
- ステップの追加・削除
- ドラッグ＆ドロップで並び替え
- 保存

### 1.2 プレビュー

- 実施画面をシミュレートしてUIを確認

## 2. レビュー者の操作

作成されたSOPを確認し、必要に応じて修正を依頼します。

## 3. 作業者（実施者）の操作

実施画面でSOPに沿って作業を進めます。

### 3.1 画面操作

- 「次へ」ボタンで次のステップへ進む
- 完了時刻は「記録」ボタンで取得
- OK/NG判定はトグルボタンで選択
- 画像添付は Ctrl+V で貼り付け
- スキップ時は理由を記述
- 未入力で「次へ」を押すと警告表示

### 3.2 出力

- 全ステップ完了後、実績データをExcelでエクスポート

## 4. チェック者の操作

リアルタイムで作業者の実施を目視で確認します。

## 5. 例外・注意点

- 通信断時は警告表示
- 未保存データはブラウザを閉じると消失
- ブラウザはEdge最新版を使用
