# SOP管理システム - 利用者向け操作ガイド

SOP作成者・レビュー者・作業者（実施者）・チェック者向けの操作説明です。

## 対象ロール

- SOP作成者
- レビュー者
- 作業者（実施者）
- チェック者

## 動作環境

- Microsoft Edge 最新版
- HTTPS環境（必須）

## 1. SOP作成者の操作

作成画面でSOPの作成・編集を行います。

### 1.1 ステップ管理

- 作業指示内容を入力
- 各ステップの設定:
  - エビデンス要否を設定
  - エビデンス説明を入力
  - 画像添付可能
  - 時刻記録必須
  - OK/NG判定必須
  - スキップ許可
- ステップの追加・削除
- ドラッグ＆ドロップで並び替え
- 保存

### 1.2 画像貼り付け

- ステップ詳細エリアでCtrl+Vで画像を貼り付け
- 画像クリックで拡大表示
- 削除ボタンで画像削除

### 1.3 キャンセル操作

- 詳細エリアのキャンセルボタンで編集前の状態に復元

## 2. レビュー者の操作

作成されたSOPを確認し、必要に応じて修正を依頼します。

## 3. 作業者（実施者）の操作

実施画面でSOPに沿って作業を進めます。

### 3.1 画面操作

- 全ステップを1画面にスクロール表示（上:ステップ情報、下:実施情報）
- OK/NG/スキップボタンで判定（横並び表示、クリックで完了日付・時刻を自動記録）
- 画像添付は Ctrl+V で貼り付け（右側エリア）
- 作業コメントを入力
- スキップ時は理由を入力（必須）
- スキップ理由未入力でスキップボタンを押すと警告表示

### 3.2 出力

- 全ステップ完了後、実績データをExcelでエクスポート

## 4. チェック者の操作

リアルタイムで作業者の実施を目視で確認します。

## 5. 例外・注意点

- 通信断時は警告表示
- 未保存データはブラウザを閉じると消失
- ブラウザはEdge最新版を使用
