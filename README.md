# SOP管理システム

定型業務の標準化・ヒューマンエラー防止・AI連携による手順作成・改定の効率化を図る、ステップ形式SOP管理システムです。

## 特徴

- **単一フォルダで完結**: npm等のビルド不要。HTMLファイルをブラウザで開くだけで動作
- **SharePoint配布対応**: ファイル配置だけで閲覧可能
- **左メニュー**: 「TOP」・「SOP作成」・「実施」の3画面
- **美しいデザイン**: 洗練された統一デザイン（Edge推奨）
- **画像ペースト対応**: Ctrl+Vで参考画像・エビデンス画像を貼り付け

## セットアップ

1. 本リポジトリのファイルを1つのフォルダに展開
2. `index.html` をブラウザ（Microsoft Edge推奨）で開く
3. 以上で導入完了

## 使い方

### 管理者（作成者）

1. **SOP作成**: 「SOP作成」メニューで新規SOPを作成
2. **ステップ追加**: 「+ ステップ追加」で工程を追加
3. **詳細編集**: ステップの▼を開き、作業指示・コメント・参考画像を入力
4. **保存**: 「保存」ボタンでlocalStorageに保存

### 作業者（実施者）

1. **SOP実施**: 「実施」メニューからSOPを選択
2. **ステップ確認**: 全ステップをスクロールで確認
3. **判定入力**: OK/NG/スキップボタンで判定
4. **エビデンス記録**: 右側のエリアに画像を貼り付け
5. **完了**: 全ステップ完了後、Excel出力

## カスタマイズ

- ブラウザ要件: Microsoft Edge（最新版）
- HTTPS配信推奨（クリップボードAPIのため）
- カスタマイズ例: テンプレート変更、拡張子変更
