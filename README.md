# SOP管理システム

定型業務の標準化・ヒューマンエラー防止・AI連携による手順作成・改定の効率化を図る、ステップ形式SOP管理システムです。

## 特徴

- **単一フォルダで完結**: npm等のビルド不要。HTMLファイルをブラウザで開くだけで動作
- **GitHub Pages / SharePoint配布対応**: ファイル配置だけで閲覧可能（HTTPS推奨）
- **統一メニューバー**: 「TOP」・「SOP作成」・「実施」の3画面に統一
- **統一カード形式デザイン**: SOP一覧・ステップ一覧・実施作業一覧を横長カード型で統一
- **画像ペースト対応**: Ctrl+Vで参考画像・エビデンス画像を貼り付け
- **エビデンス管理**: 各ステップでエビデンス要否・説明を設定可能
- **完了日付・時刻記録**: 完了日付（YYYY-MM-DD）と時刻（HH:mm:ss）を自動記録
- **実施記録**: 各ステップに作業コメントを入力可能
- **OK/NG/スキップ判定**: 横並びボタンで直感的な判定入力
- **スキップ理由入力**: スキップ時に理由入力を必須化（未入力時はエラー表示）

## セットアップ

1. 本リポジトリのファイルを1つのフォルダに展開
2. `index.html` をブラウザ（Microsoft Edge推奨）で開く
3. 以上で導入完了

または以下のURLから直接アクセス（GitHub Pages）:
<https://jundoll.github.io/sop-management-tool/>

## 使い方

### 作成者

1. **SOP作成**: 「SOP作成」メニューで新規SOPを作成
2. **ステップ追加**: 「+ ステップ追加」で工程を追加（ポップアップなしで最下部に追加）
3. **詳細編集**: ステップをクリックして詳細を開き、作業指示・コメント・エビデンス設定・参考画像を入力
4. **画像貼り付け**: Ctrl+Vで画像を貼り付け（拡大プレビュー・削除可能）
5. **保存**: 「保存」ボタンでlocalStorageに保存（変更時だけ有効）
6. **キャンセル**: 編集を破棄する場合は「キャンセル」ボタンで選択画面へ戻る

### 作業者（実施者）

1. **SOP実施**: 「実施」メニューからSOPを選択
2. **ステップ確認**: 全ステップを1画面にスクロール表示（上:ステップ情報、下:実施情報）
3. **判定入力**: OK/NG/スキップボタンで判定（横並び表示）
4. **エビデンス記録**: 右側のエリアに画像を貼り付け（Ctrl+V）
5. **作業コメント**: 実施記録をコメント入力
6. **完了日付・時刻**: 判定時に完了日付・時刻を自動記録
7. **完了**: 全ステップ完了後、Excel出力
