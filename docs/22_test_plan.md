# テスト計画書：AI連携型 ステップ形式SOPシステム

## 1. 目的

フィードバック反映による未実装機能（JSONインポートUI、P-01作業者名入力画面）の検証計画を定義する。

## 2. 対象フィードバック

- 選択画面にJSONファイルからインポートするUI/機能を追加してください
- 実施開始時に作業者名を入力する画面（P-01）を実装してください

## 3. テストケース

### 3.1 正常系テスト

#### TC-01: P-01画面表示確認
- 前提条件: SOP一覧画面(A-01)が表示されている、SOPが1件以上存在する
- テスト手順:
  1. いずれかのSOPの「実施」ボタンをクリック
- 期待結果:
  - P-01（作業者名入力画面）が表示される
  - SOPタイトルが表示される
  - 作業者名入力欄が表示される
  - 「開始」ボタンと「戻る」ボタンが表示される

#### TC-02: P-01からP-02への遷移
- 前提条件: P-01画面が表示されている
- テスト手順:
  1. 作業者名を入力
  2. 「開始」ボタンをクリック
- 期待結果:
  - P-02（ステップ実施画面）に遷移する
  - 作業者名が正しく保持されていることを確認（エクスポート時など）

#### TC-03: P-01での空欄チェック（許容）
- 前提条件: P-01画面が表示されている
- テスト手順:
  1. 作業者名を入力せずに「開始」ボタンをクリック
- 期待結果:
  - エラーにならずにP-02に遷移する（仕様上、空文字列許容）
  - またはボタンが非活性でなければ進行可能

#### TC-04: JSONインポート機能確認（既存）
- 前提条件: A-01画面が表示されている、インポート用JSONファイルが存在する
- テスト手順:
  1. 「JSONファイルから読み込み」ボタンをクリック
  2. 有効なJSONファイルを選択
- 期待結果:
  - ファイル選択ダイアログが開く
  - JSONが読み込まれ、SOP一覧に追加される
  - 成功メッセージが表示される

### 3.2 異常系テスト

#### TC-05: 無効なJSONファイルのインポート
- 前提条件: A-01画面が表示されている
- テスト手順:
  1. 「JSONファイルから読み込み」ボタンをクリック
  2. 無効な形式のJSONファイルを選択
- 期待結果:
  - エラーメッセージが表示される
  - SOP一覧に追加されない

#### TC-06: SOPが0件の場合の実施ボタン
- 前提条件: SOPが存在しない、または削除して0件になった状態
- テスト手cciones:
  1. A-01を表示
- 期待結果:
  - SOP一覧が表示されない、または空状態メッセージが表示される

### 3.3 回帰テスト（既存機能の影響確認）

#### TC-07: 管理者画面の保存機能
- 期待結果: 既存通り、保存ボタンでlocalStorageに保存される

#### TC-08: ステップ追加/削除/並び替え
- 期待結果: 既存通り、操作が正常に動作する

#### TC-09: プレビュー機能
- 期待結果: SOP全体プレビューが表示される

#### TC-10: 実施画面の各機能
- 期待結果: 時刻記録、OK/NG判定、スキップ、コメント入力、画像添付が正常に動作する

#### TC-11: Excel出力機能
- 期待結果: 完了後にExcelファイルが正常にダウンロードされる

## 4. 検証手順

1. ブラウザ（Microsoft Edge）でアプリケーションを開く
2. 上記テストケースを順番に実行
3. 結果をPass/Failで記録
4. Failがある場合は修正し、再テスト

## 5. 合格基準

- 全正常系テストケース（TC-01〜TC-04）がPass
- 全異常系テストケース（TC-05〜TC-06）が期待通りの挙動
- 全回帰テストケース（TC-07〜TC-11）がPass
- クリティカル/High項目のFailゼロ

## 6. 制約事項

- 対象ブラウザ: Microsoft Edge (最新版)
- ローカルStorageの状態はテスト実施前にクリアしてから開始
- 画像ペースト機能はクリップボードに画像がある状態でテスト
