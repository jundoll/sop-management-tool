# 実装計画書 (v1.13)

## 対象フィードバック項目
- フィードバック全体: デザイン統一、レイアウト統一、名称の実態一致
- SOP一覧画面: カード統合（ヘッダーと一覧を1カードに）
- SOP作成画面: ステップクリックでの詳細開閉、ボタン配置見直し
- 実施画面: 左右2カラムレイアウト維持、スクロール形式維持、作業者名削除

## 実装手順

### Step 1: CSS変更 - 実施画面・詳細エリアのレイアウト統一
**ファイル:** `css/styles.css`
**作業:**
1. `.player-step-row` のスタイル見直し（2カラムレイアウトの安定化）
2. `.player-step-left` / `.player-step-right` の間隔・配置を調整
3. `.step-detail-two-column` のスタイル調整（既存の詳細エリアレイアウト維持）
4. カード間の余白・フォントサイズの統一を確認

### Step 2: JS変更 - SOP一覧画面のカード統合
**ファイル:** `js/app.js`
**場所:** `doShowSelectionView()` メソッド内
**作業:**
1. 2つのカードを1つに統合
2. カードヘッダーを「SOP一覧 (N件)」のみにする
3. 新規作成/JSON読込ボタンをカード内上部に配置
4. 「SOP管理システム」ヘッダーを削除

### Step 3: JS変更 - 作成画面のステップクリックで詳細開閉
**ファイル:** `js/admin.js`
**場所:** `renderStepsList()`, `setupEventListeners()`
**作業:**
1. `.step-item` クリックイベントを追加
2. クリック時に詳細エリアの開閉をトグル
3. 削除ボタンなど操作ボタンクリック時は伝播停止して開閉しない
4. 開閉ボタン（▼/▲）のテキスト更新は維持

### Step 4: 名称の整合性確認
**ファイル:** `index.html`, `js/app.js`, `js/admin.js`, `js/player.js`
**作業:**
1. 画面上の表示名称が要件定義と一致することを確認
2. 「管理者画面」表記があれば「作成画面」に変更
3. ボタン名称の違和字がなければ変更しない
