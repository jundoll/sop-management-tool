## 実装手順

### Step 1: css/styles.css - カラーパレット変更＋ダークモード関連削除
- 背景色を`#1a2332`（青みがかったダークグレー）に変更
- カード背景を`#2c3e50`に変更
- テキスト色を白/薄いグレーに変更
- プライマリカラーを`#1a56db`（濃い青）に変更
- メニューバー背景を`#0f1a2e`（濃い青）に変更
- ダークモード用CSS変数（`[data-theme="dark"]` セレクタ等）を削除
- アイコン背景統一（白背景排除）

### Step 2: index.html - ダークモード切替ボタン削除
- メニューバー内のダークモード切替ボタン（`#dark-mode-toggle`）を削除

### Step 3: js/app.js - ダークモード処理削除
- ダークモード切替関数（`toggleDarkMode`）を削除
- ダークモードのlocalStorage保存・復元処理を削除
- 初期化時のダークモード復元処理を削除

### Step 4: js/admin.js - 画像関連バグ修正
- ペーストハンドラ内で1回のペーストで1枚のみ画像追加するよう制御
- 画像追加・削除時に`markStepDirty()`を確実に呼び出す
- 画像削除アイコンを`delete`に統一
- 画像番号表示の維持確認

### Step 5: js/player.js - 実施記録バグ修正＋詳細表示
- 判定ボタンのイベントハンドラ重複登録を防止
- 実施記録作成処理を冪等化（既存レコードがあれば更新）
- 処理中フラグで多重実行防止
- 実施記録一覧を上下2段構成で詳細表示

## 実装順序（依存関係考慮）
1. css/styles.css（見た目のベース）
2. index.html（メニューバー）
3. js/app.js（アプリ全体の初期化）
4. js/admin.js（作成画面のバグ修正）
5. js/player.js（実施画面のバグ修正）
