# 実装計画書

## 1. 実施内容

### 1.1 フィードバック全項目の実装
以下のフィードバック項目を漏れなく実装：

**全体**
- 全画面のデザイン統一（カード形式）
- 洗練されたドキュメントレイアウト
- GitHub Pages想定の環境設定
- 既存ライブラリの活用（SheetJS、Canvas API）

**SOP一覧画面**
- 横長のカード型デザインに統一
- 新規作成ボタンとJSON読み込みボタンをコンパクトに

**SOP作成画面**
1. プレビューボタンの削除
2. ステップ編集時の保存、キャンセル、削除を横並びに（余計な空白を排除）
3. 新規ステップ作成時にポップアップを表示しない（一覧最下部に空ステップを直接追加）
4. ステップ編集時に画像貼り付け（Ctrl+V）を確実に動作させる
5. 編集時、変更があったときだけ保存ボタンを有効にする（各ステップごとも同様）
6. ステップ編集時の左側の削除ボタンを削除（詳細エリア内に移動）
7. ステップ編集でキャンセルしたら編集前の状態に復元
8. 「選択画面へ」ボタンの問題を見直し
9. ステップ削除後、詳細エリアを自動的に閉じる
10. 各ステップでエビデンスの要否と説明を設定可能にする

**SOP実施画面**
11. エビデンス画像の貼り付けを可能にする
12. 完了時刻に加えて完了日付も記録する（YYYY-MM-DD HH:mm:ss）
13. 実施記録（作業コメント）を残せるようにする
14. OK/NG/スキップボタンを並べて表示
15. 各ステップのレイアウトを作業動線を考慮した配置にする
16. 上側にステップ情報、下側に実施情報を配置

## 2. 実装手順

### ステップ1: データ構造の更新
- `docs/10_requirements.md` のスキーマに基づき、以下のフィールドを追加：
  - `evidence_required` (boolean)
  - `evidence_description` (string)
- localStorageのデータ移行を考慮（既存データは後方互換性を維持）

### ステップ2: 作成画面の実装
- **HTML構造の変更**
  - プレビューボタン削除
  - ステップ詳細エリアのレイアウト変更（指示・コメント縦並び、画像横配置）
  - エビデンス設定UI追加
  - 保存・キャンセル・削除ボタンを横並びに

- **CSSの更新**
  - カード形式のデザイン適用
  - ボタンレイアウトの統一
  - レスポンシブ対応

- **JavaScriptの実装**
  - 新規ステップ作成時にポップアップを出さず、一覧最下部に空ステップ追加
  - 画像貼り付けの確実な動作（Ctrl+V）
  - 変更検知による保存ボタンの動的制御
  - キャンセル時に編集前の状態に復元
  - ステップ削除後に詳細エリアを閉じる

### ステップ3: 実施画面の実装
- **HTML構造の変更**
  - ウィザード形式から全ステップ一覧表示に変更
  - 左右2カラムレイアウト（左: 作業情報、右: 画像）
  - スキップ理由入力欄の追加
  - OK/NG/スキップボタンを横並びに

- **JavaScriptの実装**
  - 全ステップを1画面に表示
  - 完了日付・時刻の自動記録
  - エビデンス画像の貼り付け（Ctrl+V）
  - 画像の削除機能
  - スキップ時の理由入力バリデーション

### ステップ4: SOP一覧画面の更新
- ヘッダーエリアと一覧エリアを1つのカードに統合
- 横長のカード形式で表示
- 新規作成ボタンとJSON読み込みボタンを横並びに

### ステップ5: 共通コンポーネントの更新
- メニューバーの統一
- 未保存確認ダイアログの改善
- 状態管理の見直し

### ステップ6: テスト実施
- 実装後の動作確認
- 回帰テスト
- フィードバック項目の全件検証
