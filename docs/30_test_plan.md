# テスト計画書

## 1. テスト目的
フィードバック6項目（#12, #14, #15, #16, #18, #25）の修正実装および既存機能の回帰テストを実施し、品質を確保する。

## 2. テスト範囲

### 2.1 修正項目の検証（6件）
| # | フィードバック項目 | テスト観点 |
|---|-------------------|-----------|
| 12 | 詳細エリア開閉制御 | 詳細エリア内のテキスト編集時に詳細が閉じないこと |
| 14 | ボタン横並び・余計な空白排除 | 保存・キャンセル・削除ボタンが適切な幅で横並びになっていること |
| 15 | 新規ステップ作成時の詳細エリア自動展開 | 新規ステップ追加後、詳細エリアが自動的に開くこと |
| 16 | 詳細エリア保存ボタンのdisabled制御 | 変更がないときは保存ボタンがdisabled、変更後にenabledになること |
| 18 | ボタン制御と確認ダイアログ | キャンセルボタンが常時表示、未保存時に確認ダイアログが表示されること |
| 25 | 実施画面上下2段構成 | 各ステップが上段（ステップ情報）と下段（実施情報）に分割されていること |

### 2.2 回帰テスト項目
- SOPの新規作成・保存・読み込み
- ステップのCRUD操作（追加・編集・削除）
- ドラッグ＆ドロップ並び替え
- 実施画面での判定・記録
- Excel出力
- JSONインポート/エクスポート
- リロード耐性（状態復元）
- 未保存確認ダイアログ

## 3. テストケース

### 3.1 作成画面のテスト

#### TC-ADMIN-08: 詳細エリア編集時、詳細が閉じない（#12）
**事前条件**: 作成画面でステップ詳細エリアを開く
**操作**: 詳細エリア内のテキストエリアをクリックして編集
**期待結果**: 詳細エリアが閉じず、編集が継続できる

#### TC-ADMIN-09: 新規ステップ追加時に詳細エリアが自動展開（#15）
**事前条件**: 作成画面を開く
**操作**: 「+ ステップ追加」ボタンをクリック
**期待結果**: 空ステップが追加され、自動的に詳細エリアが開き、instruction/comment/evidence設定がすべて編集可能

#### TC-ADMIN-10: 詳細エリア保存ボタンのdisabled制御（#16）
**事前条件**: 作成画面でステップ詳細エリアを開く
**操作**: 
1. 初期状態で保存ボタンの状態を確認
2. 作業指示を編集
3. 保存ボタンの状態を確認
4. 保存ボタンをクリック
5. 保存後の状態を確認
**期待結果**: 
1. disabled
2. enabled
3. 再度disabled

#### TC-ADMIN-11: キャンセルボタンの常時表示（#18）
**事前条件**: 新規SOP作成画面を開く
**操作**: 画面内のボタンを確認
**期待結果**: 「キャンセル」ボタンが初期状態から表示されている

#### TC-ADMIN-12: 「作成画面へ」押下時の確認ダイアログ（#18）
**事前条件**: 作成画面でステップを追加・編集して未保存状態にする
**操作**: 「作成画面へ」ボタンをクリック
**期待結果**: 未保存確認ダイアログが表示される

#### TC-ADMIN-13: キャンセルボタンでSOP破棄（#18）
**事前条件**: 新規SOP作成画面で変更を加える
**操作**: 「キャンセル」ボタンをクリック
**期待結果**: SOPが破棄され、選択画面へ戻る

#### TC-ADMIN-14: 詳細エリアボタンの余計な空白排除（#14）
**事前条件**: 作成画面でステップ詳細エリアを開く
**操作**: 保存・キャンセル・削除ボタンのレイアウトを確認
**期待結果**: 各ボタンが内容に応じた幅で表示され、flex:1による引き伸ばしがない

### 3.2 実施画面のテスト

#### TC-PLAYER-06: ステップ上下2段構成（#25）
**事前条件**: 実施画面を開く
**操作**: 各ステップのレイアウトを確認
**期待結果**: 
- 上段に指示内容、参照画像、補足コメントが表示される
- 下段に完了日付・時刻、判定ボタン、作業コメント、エビデンス画像貼り付けが表示される
- 上下で明確に区切られている

#### TC-PLAYER-07: 既存機能の回帰テスト（実施）
**事前条件**: 実施画面でSOPを表示
**操作**: 
1. OK/NG/スキップ判定を実行
2. 作業コメントを入力
3. エビデンス画像を貼り付け
4. 全ステップ完了
5. Excel出力
**期待結果**: 各操作が正常に動作する
