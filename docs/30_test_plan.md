# テスト計画書

## 1. テスト方針
- docs/00_feedback.md の各フィードバック項目について、修正・実装されていることを1点ずつ検証する

## 2. テスト観点

3. 既存機能の回帰（SOP保存・読み込み・削除・エクスポートなど）

## 4. テスト手順
1. ブラウザで index.html を開く
2. 上記検証項目を1つずつ手動で確認
3. 各項目の結果を記録（Pass/Fail）
4. Failが発生した場合は修正して再テスト
