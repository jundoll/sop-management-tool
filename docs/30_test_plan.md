# テスト計画書

## 1. テスト概要

### 1.1 目的
フィードバック2件の修正が正常に動作することを検証する。

### 1.2 対象フィードバック
1. 作業編集欄のレイアウト改善
2. 作業者名指定後の開始ボタン動作修正

---

## 2. テストケース

### 2.1 正常系テスト

#### TC-01: ステップ編集モーダルが開く
**前提条件**: SOPが1つ以上存在する
**テスト手順**:
1. SOP一覧画面を表示
2. 「編集」ボタンをクリック
3. 管理者画面に遷移することを確認
4. ステップ一覧から「編集」ボタンをクリック
**期待結果**: モーダルが開き、フォームが表示される

#### TC-02: モーダルのレイアウト確認
**前提条件**: 編集モーダルが開いている
**テスト手順**:
1. モーダルが全画面または中央に表示されることを確認
2. 横幅が制限されていないことを確認
3. textareaが広いことを確認
**期待結果**: 編集エリアが十分な広さで表示される

#### TC-03: モーダルで保存が動作する
**前提条件**: 編集モーダルが開いている
**テスト手順**:
1. 作業指示内容を入力
2. 「保存」ボタンをクリック
**期待結果**: モーダルが閉じ、一覧が更新される

#### TC-04: モーダルでキャンセルが動作する
**前提条件**: 編集モーダルが開いている
**テスト手順**:
1. 何も入力せずに「キャンセル」ボタンをクリック
**期待結果**: モーダルが閉じる

#### TC-05: 作業者名入力後に開始ボタンで遷移する
**前提条件**: SOPにステップが1つ以上存在する
**テスト手順**:
1. 「実施」ボタンをクリック
2. 作業者名を入力
3. 「開始」ボタンをクリック
**期待結果**: ステップ1画面に遷移する

#### TC-06: ステップ遷移が正常に動作する
**前提条件**: ステップ1画面を表示中
**テスト手順**:
1. 各入力項目（時刻記録、判定、作業コメント）を入力
2. 「次へ」ボタンをクリック
**期待結果**: 次のステップに進む
**注意**: 最終ステップでは「完了」ボタンが表示される

### 2.2 異常系テスト

#### TC-07: 開始ボタンクリック時のJavaScriptエラー確認
**前提条件**: 作業者名入力画面を表示中
**テスト手順**:
1. ブラウザの開発者ツールを開く
2. コンソールを表示
3. 作業者名を入力して「開始」ボタンをクリック
**期待結果**: コンソールにエラーが出力されない

#### TC-08: モーダル外クリックで閉じる（オプション）
**前提条件**: 編集モーダルが開いている
**テスト手順**:
1. モーダル外の背景をクリック
2. キーボードのEscapeキーを押下
**期待結果**: モーダルが閉じる（既存のEscapeキー機能を確認）

### 2.3 回帰テスト

#### TC-09: SOP一覧画面
**テスト手順**: SOP一覧画面を表示
**期待結果**: 全SOPが一覧表示される

#### TC-10: 新規SOP作成
**テスト手順**:
1. 「新規SOP作成」ボタンをクリック
2. 管理者画面が開くことを確認
**期待結果**: 新しいSOPが作成され、編集可能

#### TC-11: SOP保存
**テスト手順**:
1. 管理者画面でSOPタイトルを入力
2. ステップを追加
3. 「保存」ボタンをクリック
**期待結果**: 保存成功メッセージが表示される

#### TC-12: プレビュー機能
**テスト手順**:
1. 管理者画面で「プレビュー」ボタンをクリック
**期待結果**: SOP全体プレビューが表示される

#### TC-13: ステップのドラッグ＆ドロップ並び替え
**テスト手順**:
1. ステップ一覧でドラッグ＆ドロップを実施
**期待結果**: ステップの順序が変更される

#### TC-14: 画像ペースト
**テスト手順**:
1. 編集モーダルで画像をクリップボードにコピー
2. 画像エリアで Ctrl+V を実行
**期待結果**: 画像がペーストされ、サムネイルが表示される

#### TC-15: Excel出力
**テスト手順**:
1. 作業を完了させる
2. 「Excel出力」ボタンをクリック
**期待結果**: Excelファイルがダウンロードされる

---

## 3. テスト実施方法

### 3.1 環境
- ブラウザ: Microsoft Edge (最新版)
- OS: Windows 11
- ファイル配置: プロジェクトルートで `index.html` をブラウザで直接開く

### 3.2 テスト実行
1. ブラウザの開発者ツール（F12）を開き、Consoleタブを表示
2. 各テストケースを順番に実行
3. 結果を記録

### 3.3 エラー時の対応
- コンソールエラーが発生した場合、スクリーンショットを取得
- エラーメッセージを記録
- 該当ファイルを特定し、修正

---

## 4. 合格基準

- 全テストケースが Pass であること
- JavaScriptコンソールエラーが発生しないこと
- 既存機能（回帰テスト）が正常に動作すること
