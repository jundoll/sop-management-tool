## 2. テストケース

### TC-01: 保存ボタンの重複ハンドラ防止（#24）

| 項目 | 内容 |
|------|------|
| 目的 | SOP保存時にalertが1回だけ表示されることを確認 |
| 手順 | 1. SOP一覧画面で「+ 新規SOP作成」をクリック<br>2. 作成画面でタイトルを入力<br>3. ステップを追加し、内容を入力<br>4. 「保存」ボタンをクリック |
| 期待結果 | alertが1回だけ表示される（2回表示されない） |
| 確認方法 | 目視確認 |

### TC-02: 編集画面復帰後の保存動作（#24）

| 項目 | 内容 |
|------|------|
| 目的 | 別画面から戻ってきた後も保存が正常に動作することを確認 |
| 手順 | 1. 作成画面でSOPを編集後、「選択画面へ」→「破棄して戻る」<br>2. 再度同じSOPの編集を開く<br>3. ステップを追加し、「保存」をクリック |
| 期待結果 | alertが1回だけ表示される |
| 確認方法 | 目視確認 |

### TC-03: 詳細エリアでの画像ペースト（#20）

| 項目 | 内容 |
|------|------|
| 目的 | ステップ詳細エリアでCtrl+Vによる画像貼り付けが動作することを確認 |
| 手順 | 1. 作成画面でステップを追加<br>2. 詳細エリアを開く<br>3. 参考画像エリアでCtrl+Vを押下 |
| 期待結果 | 画像が貼り付けられ、サムネイルが表示される |
| 確認方法 | 目視確認 |

### TC-04: 詳細エリア開閉後の画像ペースト（#20）

| 項目 | 内容 |
|------|------|
| 目的 | 詳細エリアを開閉した後もCtrl+Vによる画像貼り付けが動作することを確認 |
| 手順 | 1. 作成画面でステップ詳細エリアを開く<br>2. 詳細エリアを閉じる<br>3. 再度詳細エリアを開く<br>4. 参考画像エリアでCtrl+Vを押下 |
| 期待結果 | 画像が貼り付けられ、サムネイルが表示される |
| 確認方法 | 目視確認 |

### TC-05: ステップ番号の表示維持（#19）

| 項目 | 内容 |
|------|------|
| 目的 | ステップ編集時もステップ番号が表示されることを確認 |
| 手順 | 1. 作成画面で複数ステップを持つSOPを開く<br>2. 各ステップの詳細エリアを開く<br>3. ステップ番号の表示状態を確認 |
| 期待結果 | 詳細エリア開閉中もステップ番号が常に表示されている |
| 確認方法 | 目視確認 |

### TC-06: 参考画像欄の表示（#25）

| 項目 | 内容 |
|------|------|
| 目的 | 参考画像欄が適切なサイズで表示されることを確認 |
| 手順 | 1. 作成画面でステップ詳細エリアを開く<br>2. 参考画像エリアのサイズを確認<br>3. 複数枚の画像を貼り付け、表示状態を確認 |
| 期待結果 | 画像エリアが縦方向に十分なスペースを持ち、画像が適切に配置される |
| 確認方法 | 目視確認 |

### TC-07: エビデンス貼り付け欄の二重枠（#30）

| 項目 | 内容 |
|------|------|
| 目的 | エビデンス貼り付け欄に二重枠が表示されないことを確認 |
| 手順 | 1. SOP一覧画面でSOPを選択し「実施」をクリック<br>2. 実施開始画面で「開始」をクリック<br>3. 各ステップのエビデンス画像貼り付け欄を確認 |
| 期待結果 | エビデンス貼り付け欄に1つの枠のみが表示され、二重枠（入れ子の破線枠）が表示されない |
| 確認方法 | 目視確認 |

### TC-08: エビデンス画像貼り付け（#30 / 回帰）

| 項目 | 内容 |
|------|------|
| 目的 | エビデンス画像のCtrl+V貼り付けが動作することを確認 |
| 手順 | 1. 実施画面でステップのエビデンス画像エリアにフォーカス<br>2. Ctrl+Vを押下して画像を貼り付け |
| 期待結果 | 画像が貼り付けられ、削除ボタン（×）が表示される |
| 確認方法 | 目視確認 |
